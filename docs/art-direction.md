# Stage 2 art direction

Brand: **Miette Noire**. An original concept identity built around the small pleasure of a darker chocolate indulgence.

Palette: warm ivory `#f8f4ec`, cream `#eee6d8`, espresso `#30201b`, dark cocoa `#3e2922`, milk chocolate `#7b5b48`, caramel `#a46d43`.

Typography: Cormorant Garamond for display, Manrope for UI and supporting text. Both are served locally by next/font after build-time retrieval.

Image generation mode: built-in image_gen tool. Original generated photographic concepts, converted to WebP using Sharp without visual editing. No reference layout or reference image was supplied or copied. Source PNGs remain in the tool's generated_images directory; all runtime assets are inside this repository.

## public/images/signature-noire.webp

Final prompt:

Create a premium editorial food photograph for an original luxury chocolate cake patisserie website. A single beautiful round dark chocolate layer cake with silky hand-swept dark ganache, dense rich sponge layers visible in one precisely removed wedge, delicate irregular thin chocolate curls piled on top, barely a dusting of cocoa. Cake centered on a low understated dark brown ceramic pedestal. Warm ivory plaster seamless background, creamy beige tabletop, a few artfully scattered chocolate shards near lower right. Studio side lighting from upper left, long soft warm shadows, subtle grain, analog magazine aesthetic, muted espresso and cream palette, no saturated colors. Camera slightly above at three-quarter angle, entire cake and pedestal visible with generous negative space above and on both sides. No people, no lettering, no logos, no watermarks, no website interface. Photorealistic, tactile, refined, cinematic but light warm background. Square 1536x1536 composition. This is a static placeholder photo, not a 3D render.
